# Support

This is an experimental community project without commercial support commitments.

- Bugs and reproducible feature requests: [GitHub Issues](https://github.com/Thugney/project-init/issues)
- Usage and architecture: [README](README.md), [Commands](docs/COMMANDS.md), [Architecture](docs/ARCHITECTURE.md)
